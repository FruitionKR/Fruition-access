# ADR-0020: 오류 문구와 메일의 언어 선택

- 상태: 적용됨
- 관련: [API 계약](../api/README.md#오류-문구와-메일-언어), [데이터 모델](../data-model.md)

## 맥락

프론트엔드가 한국어·영어 화면을 함께 제공하게 됐다. access는 오류 응답 `message`, 요청 검증 실패 `reason`,
메일(인증번호·워크스페이스 초대·이메일 변경 알림)을 모두 한국어 문자열로 코드에 박아 두고 있었다.
영어 화면에서도 서버 문구와 메일이 한국어로 보였고, 헤더 없이 부르는 기존 클라이언트는 지금처럼 한국어를 받아야 한다.

## 결정

- **요청 언어는 `Accept-Language`로 정한다.** `AcceptHeaderLocaleResolver`에 지원 언어 ko·en과 기본값 ko를 둔다(`LocaleConfig`).
  헤더가 없거나 ko·en이 아니면 한국어다. 기본값을 JVM 언어에 맡기지 않아 서버 설정과 상관없이 같은 응답이 나온다.
- **문구는 Spring `MessageSource` 번들에 둔다.** `i18n/messages.properties`(한국어)·`messages_en.properties`(영어)와
  메일 템플릿 `i18n/mail.properties`·`mail_en.properties`다. 기본 파일이 한국어라 지원하지 않는 언어도 한국어로 떨어진다
  (`spring.messages.fallback-to-system-locale=false`).
- **오류 문구 키는 오류 코드에서 정한다.** 예외 처리기는 `error.<code>` 키를 쓰고, 문구에 값이 들어가는 예외와 한 코드에
  문구가 여럿인 예외만 `Localizable`로 인자·키를 넘긴다. 예외 자체의 메시지는 로그용 한국어로 그대로 둔다.
  번들에 키가 없으면 예외의 한국어 메시지로 응답해 번역 누락이 500이 되지 않게 하고, 키 누락은 테스트가 잡는다.
- **검증 문구는 `{validation.*}` 키로 바꿔** Spring Boot의 MessageSource 연동 interpolator가 요청 언어로 풀게 한다.
- **메일 언어는 수신자 저장 언어 → 요청 언어 → 한국어 순이다**(`MailLocaleResolver`). 같은 주소의 계정이 여럿이면
  이메일 가입 계정의 저장 언어를 먼저 본다. 초대받는 사람이 기존 사용자가 아니면 초대한 사람의 요청 언어를 쓴다.
  이메일 변경 알림은 요청 밖(outbox 작업)에서 보내므로 outbox에 넣을 때 고른 언어를 `email_change_notifications.locale`에 저장한다.
- **사용자 언어는 `users.locale`에 저장한다**(`PATCH /api/auth/me/locale`). 오류 문구는 저장 값이 아니라 요청마다
  헤더로 정한다. 로그인 전 화면도 같은 규칙으로 동작해야 하고, 프론트가 화면 언어를 헤더로 보내면 둘이 어긋나지 않는다.

## 대안과 기각 사유

- **오류 문구를 프론트가 `code`로만 번역한다.** 인자가 들어간 문구(provider 이름, 크기 제한)와 검증 `reason`까지
  프론트가 다시 만들어야 하고, 헤더 없는 기존 클라이언트와 메일에는 도움이 되지 않는다. 기각.
- **응답 언어를 저장한 `users.locale`로 정한다.** 로그인 전 요청에는 사용자가 없고, 토큰이 없는 401·검증 실패도 같은
  규칙이어야 한다. 기각.
- **예외마다 메시지 키를 생성자에서 받는다.** 모든 예외 클래스를 바꿔야 하고 로그 메시지가 키로 바뀐다. 오류 코드가 이미
  안정적인 식별자라 그것을 키로 쓴다. 기각.

## 결과

- 헤더 없는 요청은 예전과 같은 한국어 문구를 받는다. 기존 문구의 `id=`·`email=` 같은 꼬리도 그대로 옮겼다.
- 새 오류 코드를 추가하면 두 번들에 `error.<code>`를 함께 넣어야 한다(`MessageBundleConsistencyTest`가 확인).
- `/internal/**` 오류 문구, 기본 워크스페이스 이름(`새 워크스페이스`, `{이름}의 워크스페이스`)은 저장되는 데이터이거나
  서비스 사이 문구라 이번 범위에서 한국어로 둔다.
- 메일의 변경 시각은 언어와 상관없이 한국 시간(KST)으로 적는다.
